# 对于目录
# 需要将 ${directory} 更换为已被Git同步但是需要解除同步的文件夹
git rm --cached -r ${directory}

# 对于文件
# 需要将 ${file} 更换为已被Git同步但是需要解除同步的文件
git rm --cached ${file}


# 远程同步到本地

## 查看 nohup 的进程

nohup 末尾添加该命令可以指定log文件
> out.log 2>&1 &
例如：nohup python script.py > out.log 2>&1 &
